# 0.3.3 — Gameplay Mode Compatibility / 游戏模式兼容

[English](#english) · [中文](#中文)

Historical v0.3.3 release scope; this page does not validate later packages. 本页属于 v0.3.3 历史发行范围，不验收后续包。

## 中文

- 和平模式下，沙盒存档和任意资源倍率存档现在可以通过已有的有界 MCP 动作导入并继续游玩。
- 实际沙盒状态与资源倍率仍会记录和报告，但不再作为普通动作、计划重启或飞行检查点恢复的授权门禁。
- 仍不开放沙盒工具、物品/能量/科技注入、瞬间施工、瞬移、直接缓冲写入或游戏加速。
- 补充中英文 Mod README、安装/连接说明、新档与旧档使用流程，以及双模型黑盒验收链接；包内 Agent playbook 扩展了能量、采集接近、结果核销、产线验收与飞行恢复规则。
- 本机发行 Plugin 实测覆盖：新建非沙盒 1× 世界、导入非沙盒 100× 世界、导入沙盒 1× 世界；三者均以正常机制建成第一座建筑并正常保存。

## English

- Peaceful sandbox saves and peaceful saves with any resource multiplier can now be imported and operated through the existing bounded MCP actions.
- Actual sandbox state and resource multiplier remain preserved and reported, but no longer authorize or block ordinary actions, planned restart, or flight-checkpoint recovery.
- Sandbox tools, item/energy/technology injection, instant construction, teleportation, direct buffer writes, and game-speed changes remain outside the public action surface.
- Adds bilingual Mod documentation covering installation, MCP connection, new-world creation, existing-save import, and the two-model black-box comparison; the packaged Agent playbook now also covers energy, harvest approach, outcome reconciliation, production-line proof, and flight recovery.
- Local release-Plugin validation covered a fresh non-sandbox 1× world, an imported non-sandbox 100× world, and an imported sandbox 1× world; all three built their first structure through normal mechanics and saved normally.
