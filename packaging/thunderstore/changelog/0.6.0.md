# 0.6.0 — Ascension

[English](#english) · [中文](#中文)

## English

- Observe Dyson nodes, frames, shells, delivered progress and actual ray-receiver electricity.
- Preview multi-object design costs and prepare individual Native node, frame and shell changes.
- Use Native same-planet navigation and continue from water toward land through ordinary movement.
- Budget nearby ordinary construction from the measured drone reach and allow normal menu transitions time to finish after saving.

The Windows x64 package supports DSP `0.10.35.29151` and BepInEx `5.4.17`, with 76 tools and one playbook resource. In one owned peaceful non-sandbox 1× save, a 150-structure / 224-cell shell and sampled daylight receiver power were verified before and after cold recovery. See the [source-specific acceptance](https://github.com/Arcueid77/Spherewright-Lab/blob/47580368d44f0d033072be5911bc366009c7c000/scenarios/v0.6-ascension/acceptance-2026-11-20.md); exact package source and hashes are in `spherewright-manifest.json`.
