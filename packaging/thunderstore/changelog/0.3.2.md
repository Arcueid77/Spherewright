# 0.3.2 — historical release / 历史发行版

[English](#english) · [中文](#中文)

## English

- New Agent-created worlds use `Spherewright_New_*`; imported player copies use `Spherewright_Imported_*`.
- Legacy `Spherewright_M0_*` saves retain exact protected resume. Ownership never depends on a filename prefix.
- Added the packaged/MCP-discoverable opening-movement playbook for bounded landing-base/local-obstacle recovery.
- Move-stall results include structured failure/recovery fields.
- Documented normal new-game and later-confirmed player-save import flows.

This release was validated from a fresh peaceful, non-sandbox, 1× world through powered mining, smelting, automatic components and sustained automatic Electromagnetic Matrix output. Another-computer live validation of confirmed save import remained outstanding. These are historical 0.3.2 results, not acceptance of a later package.

## 中文

- Agent 新建世界使用 `Spherewright_New_*`，导入玩家副本使用 `Spherewright_Imported_*`。
- 旧 `Spherewright_M0_*` 存档保留精确 protected resume；所有权从不依赖文件名前缀。
- 新增包内及 MCP 可发现的开局移动指南，用于着陆基地和局部障碍的有界恢复。
- 移动停滞结果包含结构化失败与恢复字段。
- 记录正常新建世界及后续明确确认的玩家存档导入流程。

该发行版从新建和平、非沙盒、1× 世界开始，验证了供电采矿、冶炼、自动组件及持续自动电磁矩阵产出。已确认存档导入的另一计算机实机验证当时仍未完成。这些属于 0.3.2 历史结果，不验收后续包。
