# 首枚火箭原生观察

[English](game-api-first-rocket.md) · [简体中文](game-api-first-rocket.zh-CN.md)

源码研究固定DSP `0.10.35.29151`，`Assembly-CSharp.dll` SHA-256为`EF314425DADE51F529F184F07BE136CD3C2660A6A81515603C7226FBE7AB1D8C`。不代表实装、建设、发射或抵达已通过。

`SiloComponent.InternalUpdate`正常检查`DysonSphere.GetAutoNodeCount`，消耗配置的火箭物品、增加原生消耗寄存器，并向原生选择的节点发射火箭。实际物品是1503。`fired`是动画锁存，不是发射回执；`chargeSpend`、`coldSpend`、`time`保留原生原始单位。产品观察不调用这些模拟或发射方法。

`DysonRocket`包含原生ID、来源星球、目标层/节点、飞行进度及宇宙位置。原生池活动数为`rocketCursor - rocketRecycleCursor - 1`。原生抵达通过结构施工路径增加节点进度；`DysonNode.sp`、`spOrdered`、`spReqOrder`分别区分抵达结构点、已在途订购点及仍可订购工作。观察已有节点不创建或订购节点。

工厂详细检查增加可空`silo`观察，绑定准确实体/组件/星球/耗电器，读取库存/增产点、原生周期/目标标志、有界已有火箭/节点，以及恒星驻留工厂发射井覆盖。所有值在主线程复制。数组缺失、身份错误、池活动数量不符或越界时保持覆盖不完整、汇总数量null；部分列表只代表部分观察。不初始化球体、工厂、层或节点。动态详情不进入既有动作哈希。

界限为8192火箭/发射井池槽、最多128条火箭、最多4096个节点槽和256条节点，覆盖最多10层。越界表示覆盖未知，不报告零。本能力只服务有界首火箭观察，不是通用结构规划或发射控制器。

实际验收还须绑定正常制造的1503库存、准确发射井与原生消耗、完整来源隔离、真实对应火箭及目标抵达结构点变化。全局增长或动画不足以证明。最小原生目标创建、远端施工/配置、普通保存恢复及真实外星发射仍是分别待验工作。
