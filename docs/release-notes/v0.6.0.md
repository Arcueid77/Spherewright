# Spherewright 0.6.0

[English](v0.6.0.md) · [简体中文](v0.6.0.zh-CN.md)

Ascension adds Dyson design, construction progress and receiver-power observations to the existing interstellar factory workflow.

- Inspect nodes, frames, shells, in-flight deliveries and actual ray-receiver output; preview Native design costs and prepare individual structure changes.
- Use Native same-planet navigation and continue ordinary movement from water toward land.
- Budget nearby ordinary construction against measured drone reach and allow the normal saved return to the main menu time to finish.

## Installation and evidence

The Windows x64 build supports DSP `0.10.35.29151` and BepInEx `5.4.17`. Install a matching Plugin/MCP pair and follow the [installation guide](../release-installation.md). The interface exposes 76 tools and one playbook resource.

In one owned peaceful non-sandbox 1× save, source `e221b263` completed a 150-structure / 224-cell shell through normal production and launches. Its topology and delivered counts survived cold recovery. The same receiver produced positive sampled power across declared daylight intervals before and after recovery; this is not an all-day generation claim. See the [fixed live acceptance](https://github.com/Arcueid77/Spherewright-Lab/blob/47580368d44f0d033072be5911bc366009c7c000/scenarios/v0.6-ascension/acceptance-2026-11-20.md) for exact results and limitations. Package source and checksums are recorded with each candidate.

The measured-reach construction budget has source and CI coverage but did not receive a separate post-recovery construction exercise. The read-only walking-route preview retains a 16 m implementation range, and wireless mecha charging remains independently unproved. Package layout, installation, loaded runtime and gameplay evidence are reported separately.
