# Spherewright 0.6.0

[English](v0.6.0.md) · [简体中文](v0.6.0.zh-CN.md)

Ascension adds Dyson design, construction progress and receiver-power observations to the existing interstellar factory workflow.

- Inspect nodes, frames, shells, in-flight deliveries and actual ray-receiver output; preview Native design costs and prepare individual structure changes.
- Use Native same-planet navigation and continue ordinary movement from water toward land.
- Budget nearby ordinary construction against measured drone reach and allow the normal saved return to the main menu time to finish.

## Installation and evidence

The Windows x64 build supports DSP `0.10.35.29151` and BepInEx `5.4.17`. Install a matching Plugin/MCP pair and follow the [installation guide](../release-installation.md). The interface exposes 76 tools and one playbook resource.

**Installation erratum, 2026-11-22.** The original manual ZIP’s `INSTALL.md` and Chinese companion point to older downloads. Use the 0.6.0 manual ZIP and its checksums, or select `Arcueid_77-Spherewright` 0.6.0 in your mod manager. [Release assets](https://github.com/Arcueid77/Spherewright/releases/tag/v0.6.0) · [Thunderstore](https://thunderstore.io/c/dyson-sphere-program/p/Arcueid_77/Spherewright/)

In one owned peaceful non-sandbox 1× save, source `e221b263` completed a 150-structure / 224-cell shell through normal production and launches. Its topology and delivered counts survived cold recovery. The same receiver produced positive sampled power across declared daylight intervals before and after recovery; this is not an all-day generation claim. See the [fixed live acceptance](https://github.com/Arcueid77/Spherewright-Lab/blob/47580368d44f0d033072be5911bc366009c7c000/scenarios/v0.6-ascension/acceptance-2026-11-20.md) for exact results and limitations. The 0.6.0 packages were built from `78274df5e93ca912a2d4b6670f7eb707d3562e94`, which updates six documentation files, including the embedded guide. The [publication record](https://github.com/Arcueid77/Spherewright-Lab/blob/c012e723d75c35e1d72d82f3bb5f286926259945/releases/v0.6.0/publication-2026-11-21.md) identifies both ZIPs and their checksums.
