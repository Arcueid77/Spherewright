# Spherewright 0.5.0

[English](v0.5.0.md) · [简体中文](v0.5.0.zh-CN.md)

0.5 在工业基础上增加有界正常跨星操作、原生建筑叠放及行走诊断。

- 有界跨星探索、航线预算、正常航行/停止、翘曲器补给、外星施工及站点物流。
- 原生首帆/运载火箭检查与配置，记录各自源码范围的当地制造、真实发射、抵达和保存恢复。
- 原生叠放建造、模型/宿主兼容、完整逐层观察及仓储/配送器选择器。
- 准确大小仓分层筛选和禁格、集装机空带路径原生反向及守恒单件放带。
- 行走卡住诊断和无令牌的有界短路线预览。
- 持久原动作核销、owned 主档连续性及原生/材料/能源/返航安全门。

## 安装与证据

Windows x64、DSP `0.10.35.29151`、BepInEx `5.4.17`。两种发行布局均提供源码绑定的 Plugin/MCP 和相同 Agent 指南。将安装后的 MCP 注册为本地 stdio 服务，并按[安装指南](../release-installation.zh-CN.md)执行。

原 Voyager、首帆/火箭和叠放验收分别保留记录的实现源码。最新交审实现19cd5eb5通过6347项源码检查及本机两种包布局的冷恢复核对，47个叠放成员和完整背包保持，已观察到分层仓储/配送器选择及真实2件合堆。准确来源见[固定实现交审](https://github.com/Arcueid77/Spherewright-Lab/blob/92c9eb4d59ce304df9085fb002f03683d783fdab/releases/v0.5.0/stacking-review-delivery-2026-11-10.md)和本次发行的源码/校验清单。

已验证玩法范围为本机一个 owned、和平、非沙盒1×世界。独立管理器 profile、另一台计算机、黑雾战斗、多人/Nebula 和安装事务崩溃恢复尚未验证。所有操作遵循新鲜原生 prepare/commit、原回执、进度保护、真实物料守恒和有限返航/能源储备。
