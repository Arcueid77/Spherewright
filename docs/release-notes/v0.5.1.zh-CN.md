# Spherewright 0.5.1

[English](v0.5.1.md) · [简体中文](v0.5.1.zh-CN.md)

0.5.1 为0.5维护线增加单座风机原生回收及电网影响预览，处理 [Issue #5](https://github.com/Arcueid77/Spherewright/issues/5)。相同实现同步到0.6开发线。

## 风机回收

检查准确的已建2203风机和玩家，以 `previewOnly=true` 调用 `spherewright_prepare_dismantle`。只读 `windTurbineDismantle` 返回发电容量损失、预计电网连通分量、受影响/失去供电连接的消费者及未满足条件。

新的执行准备绑定端点、玩家和完整原生电网拓扑。提交执行一次DSP普通拆除，`windTurbineDismantleReadback` 核对目标/电力节点/发电组件消失、精确建筑物品回收、库存增产点、其他实体/预建造/连接及预计电网成员。重建通过当前库存及放置条件重新准备普通建造。

## 兼容与安装

支持Windows x64、DSP0.10.35.29151及BepInEx5.4.17，使用同一包配套的Plugin/MCP。旧请求默认值兼容，新增预览和回读字段继续采用协议1。原生拓扑有明确的完整性、拆网和电线重排容量上限。另见[协议](../protocol.zh-CN.md#configuration-transfer-and-dismantle)和[Agent指南](../agent-playbook.zh-CN.md)。

准确来源及载荷哈希记录于 `spherewright-manifest.json`。源码/构建、安装、玩法及包体验证按来源记录在[维护验证计划](https://github.com/Arcueid77/Spherewright-Lab/blob/main/scenarios/v0.5.1-wind/implementation-plan.md)。
