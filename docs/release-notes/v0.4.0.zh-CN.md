# Spherewright 0.4.0

[English](v0.4.0.md) · [简体中文](v0.4.0.zh-CN.md)

0.4 增加有界 Overseer / Foundry / Governor 观察、规划及原生执行，为后续跨恒星工作准备出发系统。最终双包的实机与发布状态分别列于下方。

- 生产、供电、物流及科研观察与诊断，与写入权限保持独立。
- 多级配方、材料、设备及基础功率规划，明确供给和有界场地/依赖估算。
- 普通材料和无人机约束下的有限蓝图施工，保留逐对象进度、取消及 fresh 续建。
- Governor 执行前声明与实际游戏 tick 长窗，不提供自主扩产或未证明的整厂平衡结论。
- 配套 MCP/Plugin 工具、嵌入/包内指南、Journal 绑定的精确 owned 主档恢复，以及另需后续确认的版本迁移披露。

冻结生产验收源码为 `2a7a98d1932c404e3a7abc2c11233d9c0b8780d9`。两份冻结布局通过本机安装、运行和同版本恢复。该源码 CI 通过 3108 项测试，接口/指南检查及有界实机验收通过。[验收摘要](../validation/v0.4.0.zh-CN.md)列出准确 hash 和固定证据；其生产长窗保留原源码及 session 范围。

最终双包源码为 `b7c0002dbe2e8f5608c5ca140b0c6326a1818021`，产品版本 `0.4.0`，面向原生 `0.10.35.29151`。SDK 8.0.424 完整锁定 Release 构建零警告/错误，3165 项测试（Contracts 73 / Core 2834 / MCP 258）、九项流程及[准确源码 CI](https://github.com/Arcueid77/Spherewright/actions/runs/39018031556)通过。双包强制双语/嵌入指南与准确 64 工具/一个资源检查通过。此次相对兼容基线只修正双语文档，没有游戏代码、能力、白名单、恢复类型或版本号变更。

最终 b7 手动与标准 Thunderstore 两种布局均已完成正常冷安装及同版本 `29151→29151` 默认 owned 主档恢复。每种布局各自独立通过一轮完整的已安装 64 工具矩阵：23 数据成功、6 预检成功、35 预期原生拒绝，矩阵 accepted/unknown 均为零。两次恢复保留持久 Journal 和已完成历史，没有再次迁移。安全拒绝证明调用时保留原生安全门，不表示执行了每项受保护写操作。对应源码安装、恢复及完整矩阵的最终独立结果审计全部通过。详见[固定对应源码实机报告](https://github.com/Arcueid77/Spherewright-Lab/blob/74a4ec3d91608467911460eaf0d317800e60309b/operations/formal-release-2026-10-17.md)。
