# Spherewright 0.6.0

[English](v0.6.0.md) · [简体中文](v0.6.0.zh-CN.md)

Ascension 在既有跨星工厂流程上增加戴森设计、施工进度及接收功率观察。

- 检查节点、框架、壳层、在途交付及接收站实际输出，预览原生设计成本，并逐项准备结构变更。
- 使用原生同星球导航，并通过普通移动继续从水面前往陆地。
- 按实测无人机距离核算近距普通施工，并在正常保存后给回主菜单留出足够时间。

## 安装与证据

Windows x64 版本支持 DSP `0.10.35.29151` 和 BepInEx `5.4.17`。安装同源 Plugin/MCP，并按[安装指南](../release-installation.zh-CN.md)连接。接口提供 76 个工具和 1 份指南资源。

**2026-11-22 安装勘误。** 原版手动 ZIP 的 `INSTALL.md` 及中文安装指南仍指向旧版本。请下载 0.6.0 手动包和对应校验和，或在 Mod 管理器中选择 `Arcueid_77-Spherewright` 0.6.0。[发行附件](https://github.com/Arcueid77/Spherewright/releases/tag/v0.6.0) · [Thunderstore](https://thunderstore.io/c/dyson-sphere-program/p/Arcueid_77/Spherewright/)

在一个自有和平非沙盒 1× 存档中，源码 `e221b263` 通过正常生产与发射完成 150 结构点、224 壳面单元；冷恢复后拓扑及已交付进度保持一致。同一接收站在恢复前后的声明日照区间内均观察到连续采样正功率，这不代表整日发电。准确结果和范围见[固定实机验收记录](https://github.com/Arcueid77/Spherewright-Lab/blob/47580368d44f0d033072be5911bc366009c7c000/scenarios/v0.6-ascension/acceptance-2026-11-20.md)。0.6.0 的打包源码为 `78274df5e93ca912a2d4b6670f7eb707d3562e94`，与实机版本相比更新了六份说明文件，其中包括内置指南。[发布记录](https://github.com/Arcueid77/Spherewright-Lab/blob/c012e723d75c35e1d72d82f3bb5f286926259945/releases/v0.6.0/publication-2026-11-21.md)列出了两种 ZIP 及其校验和。

按实测距离核算的施工预算已通过源码和 CI 检查，冷恢复后未另做针对性施工；只读步行路线预览仍有 16 米实现范围，无线塔对机甲的充电仍缺独立实证。包布局、安装、加载版本及玩法证据分别报告。
